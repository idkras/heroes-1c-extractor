что # Sync GitHub Command

Синхронизирует все изменения проекта с GitHub репозиторием.

## Что делает:
- Проверяет статус Git репозитория
- Добавляет все изменения в staging area
- Создает коммит с описанием изменений
- Отправляет изменения в GitHub
- Показывает результат синхронизации

## Использование:
Введите `/sync-github` в чате с Cursor

## Команды:
```bash
# Проверка статуса Git
git status

# Добавление всех изменений
git add -A

# Создание коммита
git commit -m "Auto-sync: $(date '+%Y-%m-%d %H:%M:%S')"

# Отправка в GitHub
git push origin master

# Проверка финального статуса
git status
```

## Ожидаемый результат:
- Все изменения добавлены в Git
- Создан коммит с временной меткой
- Изменения отправлены в GitHub
- Репозиторий синхронизирован
- Показан финальный статус
