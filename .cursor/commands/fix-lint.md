# Fix Lint Command

Автоматически исправляет ошибки линтера в проекте с обязательным чтением стандартов качества.

**Use the todo_tool to break down tasks into sub-tasks.**

## Что делает:
1. **ОБЯЗАТЕЛЬНО читает стандарты качества кода:**
   - @4.4 code quality standard
   - @1.2 AI QA Standard  
   - @4.1 TDD Documentation Standard
   - @1c-code-quality.mdc (для 1С данных)
   - @blob-processing.mdc (для BLOB данных)

2. **Запускает форматирование и проверку:**
   - `make format` для автоматического исправления
   - `make lint` для проверки качества кода
   - MyPy, Black, Ruff для статического анализа

3. **Применяет специфичные правила для 1С:**
   - Проверяет использование `row.as_list(True)` для BLOB
   - Проверяет множественные стратегии декодирования
   - Проверяет обработку ошибок кодировки

4. **Для сложных случаев применяет @why.mdc:**
   - RCA анализ корневых проблем
   - Дизайн инъекция для сложных ошибок
   - Глубокий анализ проблемных участков кода

## Использование:
Введите `/fix-lint` в чате с Cursor

## Последовательность выполнения:
```bash
# 1. Чтение стандартов качества (ОБЯЗАТЕЛЬНО)
# 2. Форматирование кода
make format

# 3. Проверка качества
make lint

# 4. Специфичные проверки для 1С
# 5. Анализ gaps и cross-check
```

## Ожидаемый результат:
- Стандарты качества прочитаны и применены
- Код отформатирован согласно стандартам
- Исправлены автоматически исправимые ошибки
- Проверены специфичные правила для 1С
- Отчет о качестве кода с анализом gaps
