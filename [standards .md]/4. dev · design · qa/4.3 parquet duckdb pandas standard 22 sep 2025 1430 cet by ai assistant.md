## 🔧 Основные принципы работы с данными

### 1. **Принцип "Data First"**
- Все данные сохраняются в формате Parquet для максимальной производительности
- DuckDB используется как основной движок для SQL-анализа
- Pandas используется только для трансформации и визуализации

### 2. **Принцип "SQL Native"**
- Все аналитические запросы выполняются через SQL
- Минимизация использования Python циклов для обработки данных
- Использование DuckDB для сложных аналитических операций

### 3. **Принцип KISS (Keep It Simple, Stupid)**
- **Простые функции** (2-3 строки кода)
- **Прямые SQL запросы** без лишних абстракций
- **Минимум кода** для максимума результата
- **Никаких сложных connection management**
- **Использование context managers** (`with` statements)

### 4. **Принцип "Research-First"** (из [Research Data Standard]([standards .md]/1. process · goalmap · task · incidents · tickets · qa/2.2 research data standard 15 jan 2025 1430 cet by ai assistant.md#🔍-принципы-исследования-данных))
- **"Сначала сырье"** - всегда начинать с просмотра реальной структуры данных
- **"Никаких предположений"** - не использовать знания о данных без проверки
- **"Полный анализ"** - анализировать ВСЕ данные без лимитов и фильтров
- **"Независимая валидация"** - проверять результаты разными методами

```python
# Стандартный паттерн извлечения данных
import duckdb
import pandas as pd

def extract_data_from_parquet(parquet_path: str, sample_size: int = None) -> pd.DataFrame:
    """
    JTBD:
    Как функция извлечения данных, я хочу извлечь данные из Parquet файла,
    чтобы проанализировать их структуру и содержимое.
    """
    conn = duckdb.connect()
    
    # Базовый запрос
    base_query = f"SELECT * FROM read_parquet('{parquet_path}')"
    
    # Добавляем sampling если указан
    if sample_size:
        base_query += f" USING SAMPLE {sample_size} ROWS"
    
    # Выполняем запрос
    result = conn.execute(base_query).df()
    conn.close()
    
    return result
```

## 🚀 Стандартные SQL паттерны

### 1. **Базовые аналитические запросы**

```sql
-- Анализ структуры данных
SELECT 
    COUNT(*) as total_rows,
    COUNT(DISTINCT column_name) as unique_values,
    MIN(column_name) as min_value,
    MAX(column_name) as max_value,
    AVG(column_name) as avg_value
FROM read_parquet('data.parquet')
WHERE column_name IS NOT NULL;

-- Группировка и агрегация
SELECT 
    category,
    COUNT(*) as count,
    SUM(amount) as total_amount,
    AVG(amount) as avg_amount
FROM read_parquet('data.parquet')
GROUP BY category
ORDER BY total_amount DESC;

-- Временной анализ
SELECT 
    DATE_TRUNC('month', date_column) as month,
    COUNT(*) as events,
    SUM(amount) as total_amount
FROM read_parquet('data.parquet')
WHERE date_column >= '2025-01-01'
GROUP BY month
ORDER BY month;
```

### 2. **Продвинутые аналитические запросы**

```sql
-- Оконные функции
SELECT 
    *,
    ROW_NUMBER() OVER (PARTITION BY category ORDER BY amount DESC) as rank,
    LAG(amount) OVER (ORDER BY date_column) as prev_amount,
    LEAD(amount) OVER (ORDER BY date_column) as next_amount
FROM read_parquet('data.parquet');

-- CTE для сложной логики
WITH monthly_stats AS (
    SELECT 
        DATE_TRUNC('month', date_column) as month,
        COUNT(*) as events,
        SUM(amount) as total_amount
    FROM read_parquet('data.parquet')
    GROUP BY month
),
growth_calculation AS (
    SELECT 
        *,
        LAG(total_amount) OVER (ORDER BY month) as prev_total,
        (total_amount - LAG(total_amount) OVER (ORDER BY month)) / 
        LAG(total_amount) OVER (ORDER BY month) * 100 as growth_rate
    FROM monthly_stats
)
SELECT * FROM growth_calculation;
```

### 1. **Анализ структуры данных**

```python
def analyze_data_structure(parquet_path: str) -> dict:
    """
    JTBD:
    Как функция анализа структуры, я хочу понять структуру и качество данных,
    чтобы подготовить план анализа.
    """
    conn = duckdb.connect()
    
    try:
        # Получаем информацию о колонках
        columns_info = conn.execute(f"""
            DESCRIBE SELECT * FROM read_parquet('{parquet_path}') LIMIT 1
        """).fetchall()
        
        # Анализируем каждую колонку
        column_analysis = {}
        for col_name, col_type in columns_info:
            stats = conn.execute(f"""
                SELECT 
                    COUNT(*) as total_count,
                    COUNT(DISTINCT {col_name}) as unique_count,
                    COUNT(*) - COUNT({col_name}) as null_count,
                    MIN({col_name}) as min_value,
                    MAX({col_name}) as max_value
                FROM read_parquet('{parquet_path}')
            """).fetchone()
            
            column_analysis[col_name] = {
                'type': col_type,
                'total_count': stats[0],
                'unique_count': stats[1],
                'null_count': stats[2],
                'null_percentage': (stats[2] / stats[0]) * 100,
                'min_value': stats[3],
                'max_value': stats[4]
            }
        
        return {
            'file_path': parquet_path,
            'total_columns': len(columns_info),
            'columns': column_analysis
        }
        
    finally:
        conn.close()
```

```python
def analyze_time_series(parquet_path: str, date_column: str, value_column: str) -> dict:
    """
    JTBD:
    Как функция анализа временных рядов, я хочу проанализировать временные паттерны,

            SELECT 
                MIN({date_column}) as start_date,
                MAX({date_column}) as end_date,
                COUNT(DISTINCT {date_column}) as unique_dates,
                COUNT(*) as total_records,
                AVG({value_column}) as avg_value,

            ORDER BY month
        """).fetchall()
        
        return {
            'time_range': {
                'start': time_stats[0],
                'end': time_stats[1],
                'unique_dates': time_stats[2],
                'total_records': time_stats[3]
            },
            'value_stats': {
                'average': time_stats[4],

            },
            'monthly_breakdown': monthly_stats
        }
```

```python
def calculate_data_quality_metrics(parquet_path: str) -> dict:
    """
    JTBD:
    Как функция расчета метрик качества, я хочу оценить качество данных,
    чтобы понять надежность данных для анализа.
    """
    conn = duckdb.connect()
    
    try:
        # Общие метрики качества
        quality_metrics = conn.execute(f"""
            SELECT 
                COUNT(*) as total_rows,
                COUNT(DISTINCT *) as unique_rows,
                COUNT(*) - COUNT(DISTINCT *) as duplicate_rows
            FROM read_parquet('{parquet_path}')
        """).fetchone()
        
        # Анализ пропущенных значений
        null_analysis = conn.execute(f"""
            SELECT 
                COUNT(*) as total_rows,
                SUM(CASE WHEN column1 IS NULL THEN 1 ELSE 0 END) as null_column1,
                SUM(CASE WHEN column2 IS NULL THEN 1 ELSE 0 END) as null_column2
            FROM read_parquet('{parquet_path}')
        """).fetchone()
        
        return {
            'completeness': {
                'total_rows': quality_metrics[0],
                'unique_rows': quality_metrics[1],
                'duplicate_rows': quality_metrics[2],
                'duplicate_percentage': (quality_metrics[2] / quality_metrics[0]) * 100
            },
            'null_analysis': {
                'null_column1_percentage': (null_analysis[1] / null_analysis[0]) * 100,
                'null_column2_percentage': (null_analysis[2] / null_analysis[0]) * 100
            }
        }
        
    finally:
        conn.close()
```

```python
def calculate_business_metrics(parquet_path: str, date_column: str, amount_column: str) -> dict:
    """
    JTBD:
    Как функция расчета бизнес-метрик, я хочу рассчитать ключевые бизнес-показатели,
    чтобы оценить эффективность бизнеса.
    """
    conn = duckdb.connect()
    
    try:
        # Базовые бизнес-метрики
        business_metrics = conn.execute(f"""
            SELECT 
                COUNT(*) as total_transactions,
                SUM({amount_column}) as total_revenue,
                AVG({amount_column}) as avg_transaction_value,
                MIN({amount_column}) as min_transaction,
                MAX({amount_column}) as max_transaction,
                COUNT(DISTINCT DATE({date_column})) as active_days
            FROM read_parquet('{parquet_path}')
            WHERE {date_column} IS NOT NULL AND {amount_column} IS NOT NULL
        """).fetchone()
        
        # Ежедневные метрики
        daily_metrics = conn.execute(f"""
            SELECT 
                DATE({date_column}) as date,
                COUNT(*) as transactions,
                SUM({amount_column}) as daily_revenue,
                AVG({amount_column}) as avg_transaction_value
            FROM read_parquet('{parquet_path}')
            WHERE {date_column} IS NOT NULL AND {amount_column} IS NOT NULL
            GROUP BY DATE({date_column})
            ORDER BY date
        """).fetchall()
        
        return {
            'overall_metrics': {
                'total_transactions': business_metrics[0],
```

### 1. **Ошибки чтения Parquet файлов**

```python
def safe_read_parquet(parquet_path: str, sample_size: int = None) -> pd.DataFrame:
    """
    JTBD:
    Как функция безопасного чтения Parquet, я хочу прочитать Parquet файл с обработкой ошибок,
    чтобы избежать сбоев при работе с данными.
    """
    try:
        conn = duckdb.connect()
        
        # Проверяем существование файла
        if not os.path.exists(parquet_path):
            raise FileNotFoundError(f"Parquet файл не найден: {parquet_path}")
        
        # Базовый запрос
        query = f"SELECT * FROM read_parquet('{parquet_path}')"
        
        # Добавляем sampling если указан
        if sample_size:
            query += f" USING SAMPLE {sample_size} ROWS"
        
        result = conn.execute(query).df()
        conn.close()
        
        return result
        
    except Exception as e:
        print(f"Ошибка чтения Parquet файла: {e}")
        return pd.DataFrame()
```

```python
def extract_1c_documents_to_parquet(
    db_connector, 
    document_types: list[str], 
    output_path: str
) -> dict:
    """
    JTBD:
    Как функция извлечения документов 1C, я хочу извлечь документы в Parquet,
    чтобы проанализировать данные цветочного бизнеса.
    """
    from src.extractors.simple_document_extractor import SimpleDocumentExtractor
    
    extractor = SimpleDocumentExtractor(db_connector)
    all_documents = []
    
    for doc_type in document_types:
        print(f"📊 Извлекаем документы {doc_type}...")
        documents = extractor.extract_documents(doc_type, limit=100)
        
        # Добавляем тип документа
        for doc in documents:
            doc['document_type'] = doc_type
            doc['table_name'] = doc_type
        
        all_documents.extend(documents)
    
    # Создаем плоскую таблицу
    flat_table = []
    for doc in all_documents:
        flat_record = {
            'table_name': doc.get('table_name', ''),
            'document_type': doc.get('document_type', ''),
            'row_index': doc.get('row_index', 0),
            'has_blob_fields': doc.get('metadata', {}).get('has_blob_fields', False),
            'field_count': doc.get('metadata', {}).get('field_count', 0)
        }
        
        # Добавляем обычные поля
        for field_name, field_data in doc.get('fields', {}).items():
            flat_record[f'field_{field_name}'] = field_data.get('value')
        
        # Добавляем BLOB поля
        for field_name, blob_data in doc.get('blob_fields', {}).items():
            if blob_data.get('value', {}).get('content'):
                flat_record[f'blob_{field_name}'] = blob_data['value']['content'][:100]
            else:
                flat_record[f'blob_{field_name}'] = f'[BLOB {blob_data.get("size", 0)} байт]'
        
        flat_table.append(flat_record)
    
    # Сохраняем в Parquet
    df = pd.DataFrame(flat_table)
    df.to_parquet(output_path, index=False, compression='snappy')
    
    return {
        'total_documents': len(all_documents),
        'flat_records': len(flat_table),
        'output_file': output_path,
        'file_size_mb': os.path.getsize(output_path) / 1024 / 1024
    }
```

```python
def analyze_flower_business(parquet_path: str) -> dict:

    JTBD:

                document_type,
                COUNT(*) as total_documents,
                SUM(CASE WHEN has_blob_fields = true THEN 1 ELSE 0 END) as docs_with_blobs,
                AVG(field_count) as avg_fields_per_doc
            FROM read_parquet('{parquet_path}')
            GROUP BY document_type
            ORDER BY total_documents DESC
```
